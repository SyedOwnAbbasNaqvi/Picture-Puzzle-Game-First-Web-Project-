## Project Description

Picture Puzzle Game is a web-based puzzle application where users solve image puzzles using drag and drop functionality.

The project uses HTML, CSS, JavaScript, and JSON Server for full CRUD operations.

---

## Features

### User Panel

- Start puzzle game
- Select difficulty
- Upload custom image
- Drag and drop puzzle pieces
- Timer and move counter
- Progress tracker
- Leaderboard system
- Form validation
- Loading and error handling

### Admin Panel

- View all player records
- Edit player names
- Delete records
- Statistics dashboard

- CSS3

- JSON Server
